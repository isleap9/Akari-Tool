UNCHANGED
The Defender warning banner, per-item checkboxes, diff arrows, Cancel/Apply buttons and all existing behavior stay exactly as they are today.
NEW — v2 FILES ONLY
Section/group headers with master checkboxes appear only when importing a version-2 profile. Importing an old v1 backup shows today's flat list — zero behavior change.
HOW IT WORKS
Unchecking a section or group header simply unchecks its items — the same SelectedIds mechanism as today. The engine (AkariProfileScope) already supports this; only the dialog wiring is missing.
